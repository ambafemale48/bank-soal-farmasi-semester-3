- 60 soal + pembahasan (7 mata kuliah: Farmakologi, Sediaan Padat, Kimia Analisis II, Biokimia, Mikrobiologi, Farmakognosi, Farmasi Fisika)
- Dua mode latihan: Langsung (pembahasan instan) dan Ujian (nilai + bedah soal di akhir)
- Progres per mata kuliah, riwayat sesi, bank soal, tambah soal sendiri, generator soal
